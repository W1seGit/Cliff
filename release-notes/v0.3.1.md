# Cliff v0.3.1

A patch release for two problems found right after v0.3.0.

## Fixes

- The Minecraft EULA prompt now appears whenever you press Start on a server that has not accepted it. Cliff reads `eula.txt` when you start or restart, instead of watching the console for a message, so it works no matter which page you are on and even when a server with many mods fails before printing anything useful. After you accept, the server starts on its own.

## Logs

- `cliff logs` now tells you what Cliff is doing. It records when a server starts, when it is ready (with the startup time), when it stops, and its exit code.
- If a server fails to start or crashes, the log includes the last lines of that server's output, so the reason is visible without opening the console.
- The log shows the first-time Java download, every change made through the dashboard (for example saving settings or starting a server), and any request that was refused or failed, with the reason.
- Routine reads and signed-out checks are kept out of the log so it stays readable.
