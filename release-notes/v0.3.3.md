# Cliff v0.3.3

A patch release for one Windows problem found after v0.3.2.

## Fixes

- On Windows, black console windows no longer flash open and closed every few seconds while a server is running. Cliff checks the server's CPU and memory every 5 seconds with a PowerShell command, and when Cliff was started with `cliff start` (no console of its own) Windows opened a window for each check. The same fix covers the other programs Cliff starts in the background: the server itself, stopping a server, the Playit agent, the mod loader installer and the update check. Nothing changes on macOS or Linux.
