# Cliff v0.3.0

A redesigned dashboard, safer updates, a more reliable command line, and a set of fixes to starting, uploading and editing servers.

## Safer updates

- Cliff now test-starts the downloaded version before changing anything, then copies its own database, then stops your server, then installs. A failed download no longer stops a running server.
- After an in-app update, the old version watches the restart. If the new one is not healthy within 45 seconds, it puts the old version back and starts it again. `cliff update` does the same.
- The dashboard and `cliff update` show each step as it happens, and afterwards say whether Cliff updated or went back to the previous version.
- The update pop-up has a "Skip this version" checkbox that keeps it quiet until the next release.
- App Settings > Updates shows what the safety copies use (the previous version, about 14 MB, and small database copies) and can delete them. `cliff cleanup` does the same, and `cliff rollback` undoes the last update by hand.
- An update you started keeps running if you close the browser tab.

## Command line and install

- `cliff stop`, `status` and `logs` find the daemon even when it was started another way or with a custom data folder, and confirm a process is really Cliff before touching it.
- `cliff stop` shuts Cliff down cleanly on every platform, so running servers stop and worlds are saved. Windows no longer hard-kills the daemon.
- `cliff uninstall` refuses a folder that is not a Cliff install, asks before stopping anything, supports `--keep-data`, and removes the PATH entries the installer added.
- `cliff logs -f` follows the log.
- Re-running the installer upgrades in place and keeps your servers and settings. It never deletes a folder that is not a Cliff install, and it makes `cliff` available in the current terminal where it can.

## Dashboard redesign

- One page layout across every screen, full-width content, one accent colour taken from the Cliff logo, and consistent tables, buttons and dialogs.
- The Mods and Plugins marketplace has a slimmer filter sidebar that scrolls on its own, every platform shown with its logo, a Server / Both / Client toggle, removable filter chips and larger result rows.
- The server bar shows a dot-grid glow that breathes while a server starts and holds steady once it is running.
- Selecting rows shows a floating bar in the same style as the Settings save bar.
- The `server.properties` and file editors share one code editor with line numbers and highlighting.

## Servers

- A server is no longer reported as started before it is actually ready.
- New NeoForge and Forge servers launch correctly.
- Uploads accept several files at once and recognise mods, plugins, datapacks and bundles by their contents instead of the file name.
- The EULA prompt no longer reappears after you accept it.
- Importing or cloning a server refuses to copy a folder into itself.

## Backups

- Removed "auto snapshots" (a snapshot before every mod change), which used disk space and were rarely wanted. Scheduled snapshots stay, and now work on their own.

## Security

- The daemon checks browser origins, rate-limits sign-in and uses secure cookies over HTTPS. Using Cliff from another device on your network works as before.

## Upgrading

Updates are applied by the version you are running, so the automatic rollback and progress steps start working for the update after this one. Updating to v0.3.0 from an older release uses that release's own updater.
